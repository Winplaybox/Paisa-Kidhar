# Play Store listing

**App name (30):** Paisa Kidhar? Daily Budget

**Short description (80):**
Daily budget + nightly report card. Pata karo salary kidhar gayi 💸

**Full description:**

Salary aati hai… aur gayab ho jaati hai? 🤔

Paisa Kidhar? tumhari monthly income ko ek simple **daily budget** mein badal deta hai — aur har raat batata hai ki aaj tumne kaisa behave kiya.

☀️ **Har subah** — "Good morning! Aaj ka daily income budget ₹3,333 hai."
➖ **Din bhar** — Coffee −₹250, Blinkit −₹600, Swiggy −₹500… sab live minus hota hai
🌙 **Har raat** — Report card: "Budget ₹3,333 tha, tumne ₹4,200 kharch kiye. Grade D 💸"

**Kyun use karein?**
• Ek tap quick-add — Coffee, Blinkit, Zepto, Swiggy, Amazon, Uber
• Bank SMS paste karo — amount, merchant, category khud nikal aate hain (HDFC, SBI, ICICI, Axis, Kotak, UPI)
• Bank statement import — CSV, Excel, PDF
• Beautiful charts — category donut, daily bars vs budget, month pace, weekday pattern, 6-month trend
• Smart insights — subscriptions, chhote kharchon ka leak, spike days, month-end warning
• Carry forward — kal bachaya toh aaj zyada
• Streaks 🔥 — kitne din lagatar budget mein rahe
• Google sign-in, data har phone pe sync
• Privacy first — tumhara data sirf tumhara. Export ya delete kabhi bhi

Kabhi kabhi higher salary nahi chahiye — bas koi chahiye jo bataye current salary kidhar ja rahi hai. 😅
