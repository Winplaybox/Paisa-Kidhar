# UX flows

## Couple onboarding
Welcome → Continue with Google → Supabase session → couple profile → wedding details → create first registry → add goals → preview → publish → share QR/link.

## Guest contribution
Open shared link/QR → view couple story and goals → choose goal → enter amount → choose public name/anonymous + optional message → review total/fee → demo/test payment → server verification → confirmation.

## Couple insights
Dashboard → date range/goal filter → KPI cards → contribution timeline → goal comparison → contribution distribution → CSV export.

## Admin
Protected admin sign-in → role verification → aggregate user-base dashboard → search/moderation → audit trail.

## UX requirements
All flows need loading, empty, error, offline/retry and success states. Payment and authentication screens must remain free of ads.
